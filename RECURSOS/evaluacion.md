# Evaluación y Progreso

## Por Cada Semestre

| Componente | Porcentaje |
|-----------|----------|
| Examen teórico (conceptos, análisis) | 40% |
| Proyecto integrador | 30% |
| Ejercicios y pequeños proyectos | 20% |
| Participación | 10% |

## Criterios de Aprobación

- **Mínimo 60%** en examen
- **Proyecto funcional completo**
- **Code review**: Calidad de código, design patterns, SOLID

## Hitos de Empleabilidad

| Semestre | Hito |
|---------|-----|
| **IV** | Programa en C++ de mediana complejidad |
| **VI** | Arquitectura de software profesional |
| **VIII** | Sistemas de bases de datos |
| **X** | APIs RESTful completas |
| **XII** | 1-2 proyectos full-stack en portafolio GitHub |
