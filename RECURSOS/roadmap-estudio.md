# Roadmap de Estudio

## Plan de 156 Semanas (~3 años)

### Fase 1: Fundamentos (Semanas 1-12)

| Semana | Tema | Objetivo |
|-------|------|----------|
| 1-2 | Teoría computación | Entender qué es computable |
| 3-4 | Sistemas numéricos | Binario, hex, tipos de datos |
| 5-6 | Álgebra booleana | Lógica, puertas, circuitos |
| 7-8 | Arquitectura I | CPU, memoria, instrucciones |
| 9-10 | Sistemas operativos I | Procesos, threads, memoria |
| 11-12 | Lógica matemática | Conjuntos, inducción |

### Fase 2: Estructuras (Semanas 13-24)

| Semana | Tema | Objetivo |
|-------|------|----------|
| 13-15 | Grafos | BFS, DFS, Dijkstra |
| 16-18 | Árboles | BST, AVL, heaps |
| 19-21 | Estructuras avanzadas | Hash, Fenwick, segment trees |
| 22-24 | Búsqueda strings | KMP, Boyer-Moore |

### Fase 3: Algoritmos (Semanas 25-36)

| Semana | Tema | Objetivo |
|-------|------|----------|
| 25-26 | Complejidad | O, Θ, Ω |
| 27-28 | Ordenamiento | Merge, quick, heap sort |
| 29-30 | Programación dinámica | DP problemas clásicos |
| 31-32 | Algoritmos greedy | greedy selection |
| 33-36 | Repaso + proyecto | Proyecto integrador |

### Fase 4: C++ (Semanas 37-52)

| Semana | Tema | Objetivo |
|-------|------|----------|
| 37-38 | Intro C++ | Sintaxis, tipos, control |
| 39-40 | Punteros y memoria | new, delete, arrays |
| 41-42 | STL | vector, map, algorithms |
| 43-44 | Templates | Genéricos |
| 45-46 | Excepciones | try, catch |
| 47-48 | Threads | std::thread |
| 49-52 | Proyecto C++ | Programa funcional |

### Fase 5: OOP (Semanas 53-68)

| Semana | Tema | Objetivo |
