# Modelo OSI

## Teoría

### Las 7 Capas

1. **Física**: bits → señales eléctricas
2. **Enlace**: frames, MAC addresses
3. **Red**: paquetes, IP addresses
4. **Transporte**: segmentos, puertos TCP/UDP
5. **Sesión**: gestión de sesiones
6. **Presentación**: formato de datos
7. **Aplicación**: protocolos HTTP, FTP, etc.
