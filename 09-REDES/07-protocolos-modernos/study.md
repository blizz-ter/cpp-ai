# Protocolos Modernos

## Teoría

- **HTTP/2**: Multiplexing, server push, header compression
- **HTTP/3 (QUIC)**: UDP-based, 0-RTT connection
- **WebSocket**: Comunicación bidireccional
- **gRPC**: RPC moderno con Protocol Buffers
- **WebRTC**: Comunicación P2P en tiempo real
