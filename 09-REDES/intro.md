# Redes

## Objetivo del Módulo
Entender redes para comunicar clientes y servidores de juegos.

## Temas del Módulo

| Tema | Descripción |
|------|-------------|
| 01-modelo-osi | Modelo OSI |
| 02-capa-enlace | Capa de enlace |
| 03-capa-red-ip | Capa IP |
| 04-capa-transporte | TCP/UDP |
| 05-capa-aplicacion | HTTP, WebSockets |
| 06-seguridad-redes | TLS, certificados |
| 07-protocolos-modernos | HTTP/2, HTTP/3 |

## Aplicación en MuServer

- **Protocol.cpp**: Protocolo TCP custom
- **Winsock2**: Conexiones de red
- WebSockets para cliente web
