# Patrones de Diseño

## Objetivo del Módulo
Aprender los patrones de diseño esenciales para arquitecturas de servidores.

## Temas del Módulo

| Tema | Descripción |
|------|-------------|
| 01-patrones-creacionales | Singleton, Factory, Builder |
| 02-patrones-estructurales | Adapter, Decorator, Facade |
| 03-patrones-comportamiento | Observer, Strategy, Command |
| 04-patrones-arquitectonicos | MVC, Repository, Unit of Work |
| 05-solid-principles | Principios SOLID |

## Aplicación en MuServer

- **Singleton**: GameServer, DataServer connections
- **Observer**: Event system
- **Command**: Protocol handlers
