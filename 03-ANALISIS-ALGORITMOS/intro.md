# Análisis de Algoritmos

## Objetivo del Módulo
Aprender a analizar y diseñar algoritmos eficientes para servidores de juegos.

## Temas del Módulo

| Tema | Descripción |
|------|-------------|
| 01-complejidad | Notación Big-O, análisis temporal |
| 02-ordenamiento | Sorting algorithms |
| 03-busqueda | Binary search, search trees |
| 04-programacion-dinamica | Dynamic programming |
| 05-algoritmos-greedy | Algoritmos voraces |
| 06-busqueda-combinatoria | Backtracking, Branch & Bound |
| 07-algoritmos-probabilisticos | Randomizados, Monte Carlo |

## Aplicación en MuServer

- **Ordenamiento**: Listas de jugadores, ranking
- **Búsqueda**: Items en inventario
- **DP/Greedy**: Cálculo de rutas óptimas
