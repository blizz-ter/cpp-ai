# Introducción a Python

## Teoría

Python es un lenguaje de programación interpretado de alto nivel:
- **Sintaxis limpia**: Sangrías (indentación) definen bloques
- **Tipado dinámico**: No declaración de tipos
- **Multiparadigma**: Procedural, OOP, funcional
- **Gran ecosistema**: Librerías para todo

### ¿Por qué Python en Backend?

- Desarrollo rápido
- Gran cantidad de Librerías
- comunidad grande
- Frameworks como Flask, Django, FastAPI
