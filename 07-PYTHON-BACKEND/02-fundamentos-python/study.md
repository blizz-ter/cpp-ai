# Fundamentos Python

## Teoría

### Colecciones

- **list**: [], mutable, orden indexing
- **tuple**: (), inmutable
- **dict**: {}, clave-valor
- **set**: {}, sin duplicados

### Control Flow

```python
if level > 10:
    print("Avanzado")
elif level > 5:
    print("Intermedio")
else:
    print("Novato")
```

### Loops

```python
for i in range(10):
    print(i)
```
