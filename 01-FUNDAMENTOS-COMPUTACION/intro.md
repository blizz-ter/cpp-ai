# Fundamentos de Computación

## Objetivo del Módulo
Introducción a los fundamentos teóricos de la computación que sustentan todo servidor de juegos moderno.

## Temas del Módulo

| Tema | Descripción |
|------|-------------|
| 01-teoria-computacion | Teoría de autómatas y computabilidad |
| 02-sistemas-numericos | Binario, hexadecimal, operadores |
| 03-algebra-booleana | Lógica booleana y puertas lógicas |
| 04-arquitectura-computadoras | CPU, memoria, sistemas operativos |
| 05-sistemas-operativos-I | Procesos, threads, memoria virtual |
| 06-logica-matematica | Lógica proposicional y predicados |

## Aplicación en MuServer

El código del MuServer implementa estos fundamentos en:
- **Protocol.cpp**: Parser de protocolos usando autómatas
- **stdafx.h**: Headers del sistema operativo Windows
- **User.h**: Estructuras de datos en memoria
