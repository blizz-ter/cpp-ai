## Cómo Usar Este Sistema

### Metodología de Estudio

1. **Lee la teoría** en cada archivo `study.md`
2. **Estudia el código** del MuServer que se referencia
3. **Practica los ejercicios** al final de cada tema
4. **Completa el proyecto** al final de cada parte

### Conexión con el MuServer

Cada tema del currículo está conectado al código real del proyecto:

| Tema | Código MuServer |
|-----|-------------|
| Tipos en C++ | `stdafx.h` (BYTE, WORD, DWORD) |
| Objetos jugador | `User.h` (OBJECTSTRUCT) |
| Items | `Item.h` (CItem) |
| Protocolo de red | `Protocol.cpp` |
| Redes | `SocketManagerModern.h` |
| Base de datos | `ScriptSql/`, `DSProtocol.cpp` |
