# Estructuras Discretas

## Objetivo del Módulo
Dominar estructuras de datos discretas esenciales para cualquier servidor de juegos.

## Temas del Módulo

| Tema | Descripción |
|------|-------------|
| 01-teoria-grafos | Teoría de grafos y algoritmos |
| 02-arboles-especializados | Árboles B, AVL, Red-Black |
| 03-estructuras-avanzadas | Heaps, Skip Lists, Tryes |
| 04-busqueda-strings | Algoritmos de string matching |

## Aplicación en MuServer

- **Grafos**: Mapas del juego, rutas de NPCs
- **árboles**: Inventario jerárquico, skill trees
- **Heaps**: Colas de prioridad de eventos
